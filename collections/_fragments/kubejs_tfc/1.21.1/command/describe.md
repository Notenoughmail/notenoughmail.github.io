form: describe <data_type> <id>

    - '`<data_type>`[[1]]: The data type to retrieve the entry from'

exp: Prints an overview of the data contained in a data entry

An example: `/kubejs_tfc describe tfc:fuel tfc:coal`{: .language-command }
